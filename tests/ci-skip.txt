# CI 跳過清單 —— **每一行都是待辦,不是永久豁免。**
#
# `scripts/run-tests.sh` 只在 `CI=true` 時讀這份(本機跑永遠跑全套)。
# 格式:`<測試檔名>  # <為什麼在 CI 上跑不起來>`
#
# 為什麼要有這份而不是讓 CI 紅著、或悄悄不跑:
#   · 紅著 → 外部貢獻者看到紅勾會以為是自己弄壞的,或乾脆學會無視 CI。
#     一條沒人修的紅線會讓整份報告失去意義。
#   · 悄悄不跑 → 更糟。看起來「全綠=全都驗過了」,實際上沒有。
#   runner 會把跳過的檔名與理由**印出來**並算進總數,所以不會假裝覆蓋。
#
# 共同病根:這幾支依賴的不是程式碼,而是**維護者那台機器上的東西**
# (Hermes agent 安裝、codex binary、macOS 的 zsh)。要讓它們進 CI,正解是
# 讓它們在依賴缺席時 `SkipTest` 而不是炸掉 —— 那是下一刀,不是這一刀。

#   那才是正解 —— 列在這裡只有 CI 生效,本機還是紅著。
